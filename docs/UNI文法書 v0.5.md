# UNI文法書 v0.5

全母国語プログラミング言語 UNI の完全な文法リファレンス。ここに載っていない構文は存在しない。

---

## 1. 字句規則(レキサ)

### 1.1 正規化

ソースは解釈前に正規化される。**どちらで打っても同じ**:

| 入力 | 正規化後 |
|---|---|
| `ＦＯＲ` / `for` / `For` | `FOR` |
| `１０` | `10` |
| `＝` | `=` |
| `｛｝` | `{}` |
| `−５` `－５` | `-5` |

保護される記号(正規化対象外): `、` `。` `「` `」` `’` `￥` `；`

### 1.2 漢数字

文脈限定で数値に変換される:

- **順序参照の直前**: `二個目` → `2個目`、`十番目` → `10番目`
- **単独(他の漢字・かなに隣接しない)**: `FOR 一 …` → `FOR 1 …`
- 変換されない例: `「一部`(変数名の一部)、`「合計十`のような識別子内

### 1.3 コメント

```
・・行末までコメント
// 半角でも同じ
```

`・`はJIS配列で`/`キーの日本語モード側——`//`と物理的に同じキー操作。文字列`’〜’`の中の`・・`はコメントにならない。

### 1.4 字種判定(一文字目で品詞が確定)

| 一文字目 | 品詞 |
|---|---|
| `「` | 変数 |
| `￥` | 役割修飾子(引数宣言、`￥「名前`) |
| ひらがな列 | 関数・動詞 |
| 全角/半角大文字英字 | 制御キーワード |
| 数字・`-` | 数値リテラル |
| `’` | 文字列リテラル |

### 1.5 文の区切り

- `。` = 文終端(セミコロン相当)
- 改行でも文は閉じる
- ブロック`{`の閉じ`}`は省略可(インデントで自動クローズ)

## 2. 変数

```
「りんご                 … 宣言(0で自動初期化)
「りんご　１０　から      … 初期値つき宣言(からマーカー)
「りんごの数　＝　５。   … 代入(＝)
```

- 変数名に「の」など任意の文字を含められる(`「りんごの数`)。終端=空白/`＝`/`、`/`。`
- 初出の変数は0/空で自動初期化される(Java投影でも辻褄が合う)

## 3. リテラル

| 種類 | 書き方 | 例 |
|---|---|---|
| 数値 | 全角半角どちらでも、負数・小数可 | `10` `１０` `−5` `1.5` |
| 文字列 | `’〜’`(明示閉じ) | `’こんにちは’` |
| 文字列補間 | 文字列内の`「名前」` | `’こんにちは「なまえ」さん’` |
| ヌル | `ヌル` | 各言語のNone/null |

補間は`」`が閉じ記号。Python=f文字列、PHP=`"{$x}"`、JS=テンプレートリテラル、Java=`+`連結に投影される。

## 4. 演算

### 4.1 演算動詞(対象は暗黙または明示)

| 動詞 | 意味 |
|---|---|
| `足す`/`たす` | += (リスト対象ならappend) |
| `引く`/`ひく` | -= |
| `掛ける`/`かける` | *= |
| `割る`/`わる` | /= |
| `あまり、a、b`(組み込み関数) | a % b |

```
「りんご　１　足す        … 暗黙対象(直前に導入した変数)
「りんご　「数　足す      … 空白区切りで対象を明示
「りんごに５足す          … 「に」で対象を明示(同義)
```

### 4.2 比較(IF/WHILEの条件で使う)

| マーカー | 意味 |
|---|---|
| `より大きい` / `より小さい` | > / < |
| `以上` / `以下` | >= / <= |
| `と同じ`(とおなじ) | == |
| `とちがう`(と違う) | != |

### 4.3 論理

| 語 | 意味 |
|---|---|
| `かつ` | AND |
| `または` | OR |
| `〜でない`(条件末尾) | NOT |

```
IF　「てん　８０以上　かつ　「てん　９０より小さい｛
IF　「てん　５０以下でない｛
```

## 5. 制御構文(キーワードは英名・全角大文字可)

### 5.1 分岐

```
IF　条件｛
　…
ELSE　IF　条件｛
　…
ELSE｛
　…
```

### 5.2 数値ループ

```
FOR　開始値　「変数が　終値まで　刻みずつ　ふえる｛
```

- スロットは**語順自由**(マーカーが役割を決める): 開始値(裸の数値)/`「Xが`=ループ変数/`Nまで`=終値(変数`「上限まで`も可)/`Nずつ`=刻み/`ふえる`・`へる`=方向
- `１ずつ`は省略可(既定=1、昇順)

### 5.3 リスト反復

```
FOR　「リスト　から　「要素が｛     … まで が無ければリスト反復
FOR　「リスト　から｛              … 要素変数省略時は「それ
FOR　「リスト　から２ずつ｛        … 飛ばし読み
```

### 5.4 条件ループ・脱出

```
WHILE　条件｛
BREAK        … ループ脱出
CONTINUE     … 次の周へ
```

### 5.5 例外

```
TRY｛
　…
CATCH｛
　…
```

注: 構文は4ターゲット共通だが、**何が例外を投げるか**はターゲット依存(層2の性質)。

## 6. 関数

### 6.1 定義(`定義`のみ日本語キーワード。関数名はひらがな)

```
定義　りんごをたす　￥「数｛
　「りんご　０　から
　「りんご　「数　足す
　最後に「りんご渡す
```

- `￥「名前` = 仮引数(役割修飾子`￥`+変数シジル`「`の合成)。本文では`「数`で参照
- 複数引数: `定義 わりざんする ￥「分子 ￥「分母 {`
- `渡す` = return(`最後に`は修飾語)
- 関数名は不可分の一語(中の「を」は分解されないが、英名変換時は語順反転に使われる)

### 6.2 呼び出し(括弧なし・`、`区切り)

```
「答え　＝　りんごをたす、５。
「答え　＝　きく。              … 引数ゼロは名前だけ
```

## 7. コレクション(LL体系)

### 7.1 リテラル

```
「くだもの　＝　LL　’りんご’、’みかん’。      … リスト
「めも　＝　LL　りんご、みかん。               … LL内の裸語は文字列扱い
「から箱　＝　LL。                             … 空リスト
「じしょ　＝　LL　くだもの；りんご、数；３。   … ；があれば辞書(キー；値)
```

- **LLは共用かっこ**: `；`の有無だけでリスト/辞書が分岐
- LL内で使えるもの: 裸語(=文字列)、`’文字列’`、数値、`「変数`、`ヌル`、入れ子LL

### 7.2 入れ子(v0.5)

内側のLLだけ`」`で閉じる。最外殻は従来どおり`。`で閉じる:

```
「表　＝　LL　LL　１、２、３」、LL　４、５、６」。
「表２　＝　LL　行あ；LL　７、８」、行い；LL　９」。
```

### 7.3 番地(読み)

```
「くだもの　３個目          … 位置(つ目/個目/番目は同一視、1始まり)
「じしょ　きかい            … キー
「表　１つ目　２つ目        … 連鎖番地 → 表[0][1]
```

そのまま式として使える: `「なか ＝ 「じしょ くだもの。` / `「じしょ きかい 出す。`

### 7.4 書き込み

| 操作 | 構文 | 意味 |
|---|---|---|
| 追加 | `「くだもの ’もも’ 足す` | append(足すの多態) |
| 置換(位置) | `「めも ２個目 ぶどう かえる` | めも[1] = "ぶどう" |
| 置換(キー) | `「じしょ くだもの １つ目 すいか かえる` | じしょ["くだもの"]=(1つ目=出現指定・省略可) |
| 削除(詰める) | `「くだもの ２個目 消す 左` | 要素が消え、左に詰まる(長さ−1) |
| 削除(穴) | `「くだもの ２個目 消す ヌル` | ヌルが残る(長さ不変) |

## 8. 入出力

| 構文 | 意味 | 投影 |
|---|---|---|
| `値 出す。` | 出力 | print / echo / console.log / System.out.println |
| `「x ＝ きく。` | 1行入力 | input() / fgets(STDIN) / readFileSync(0) / Scanner |

## 9. ターゲット互換層

### 9.1 組み込み関数(移植可能・全ターゲット対応)

| 名前 | 意味 | 投影例 |
|---|---|---|
| `ながさ、「リスト` | 要素数 | len / count / .length / .size() |
| `へいほうこん、９` | 平方根 | math.sqrt / sqrt / Math.sqrt |
| `あまり、a、b` | 剰余 | % |
| `きく` | 入力 | 上表参照 |

### 9.2 EX(ターゲット固定の脱出ハッチ)

```
「いま　＝　EX’time.time’。
```

ネイティブ関数を生呼び出しする。Python投影ではimportが自動挿入される。**移植性を失う**代わりに変換先の全ライブラリが使える。


## 12. コマンドライン

```
python3 uni.py program.nihongo --target=py|php|js|java  [--names=native|romaji|en]  [--lang=ja|en]
```

- `--names=en`: 識別子を英名に自動変換(助詞分割→語彙表→ローマ字→snake/camel規約→予約語回避)。`りんごをたす`→`addApple`(`を`で動詞先行に語順反転)
- `--names=romaji`: ローマ字化のみ

## 13. 多言語フロントエンド(対応表方式)

英語・中国語・アラビア語のフロントエンドが同梱。各15〜20行の対応表(シジル・マーカー・動詞・句読点)だけで、パーサ本体は無変更。

```
define sum \$limit { $total from 0 … }        … 英語
定义 求和 \$上限 { $总 从0 … }                … 中国語
عرف مجموع \$حد { $كلي من ٠ … }               … アラビア語
```

**対応表を書くときの規則**(アラビア語で発見): 前置マーカーは語境界(`\b`)を必須にし、複合句(例: أكبر من)を単独マーカーより先に適用する。
